PEAK VPN
Автоматизированная экосистема для продажи и управления VPN-доступом через Telegram-бота. Построена на базе панели Marzban, протокола VLESS (gRPC / Reality) и эквайринга ЮKassa.

Архитектура системы
1. Главный сервер управления (Marzban)
Центральный узел («мозг» системы), который отвечает за хранение базы данных, учёт трафика, управление пользователями и настройку подключений.

• Развёртывание: Выделенный VPS на Ubuntu. Работает в изолированных Docker-контейнерах (панель, база данных, веб-сервер). 
• Безопасность и DNS: Панель администратора защищена через Cloudflare Proxy и Zero Trust. При этом домены самих VPN-нод работают в режиме DNS-only (без проксирования), что необходимо для корректной работы маскировки VLESS Reality. 

<img width="1280" height="498" alt="image" src="https://github.com/user-attachments/assets/4d982223-fcb2-46d1-95ae-a0c41bf26111" />



• Обход блокировок: Трафик упаковывается в VLESS + gRPC (HTTP/2-потоки), благодаря чему система обходит глубокий анализ пакетов (DPI) провайдеров. 

<img width="769" height="795" alt="image" src="https://github.com/user-attachments/assets/d48c6940-cc58-46ed-b1dc-3563a85515d0" />

• Интеграция: Управление панелью происходит через REST API (авторизация по JWT-токенам). Бот автоматически создает, продлевает и запрашивает ключи через API. 
2. Telegram-бот (Интерфейс пользователя)
Единственная точка контакта с клиентом: от выбора тарифа и оплаты до получения инструкций и поддержки.

<img width="591" height="1280" alt="image" src="https://github.com/user-attachments/assets/2dfa96bc-3c7f-47bc-b848-c7f5e1198cf1" />


• Автономия: Бот работает через Long Polling — ему не нужны открытые вебхуки или публичный IP-адрес. 
• Тарифы и тестовый период: На всех тарифах доступен безлимитный трафик. Бот умеет выдавать бесплатный пробный период, предварительно проверяя подписку пользователя на ваш Telegram-канал через Bot API. 
• Приём платежей: Оплата через ЮKassa. Статус проверяется через фоновый опрос (polling) при нажатии кнопки «Я оплатил», что избавляет от необходимости поднимать вебхуки. После успешной оплаты Marzban мгновенно выдаёт подписку. 
• Управление ключом: Пользователь получает персональный UUID. В любой момент он может перевыпустить ключ в боте — старая ссылка сбросится, а вместо неё создастся новая. 
• Панель администратора: Выдача доступа вручную прямо из чата одной командой (/grant <tg_id> <дней>), а также мгновенные PUSH-уведомления админу о каждой покупке или активации триала. 
Технологический стек бота:

• Aiogram 3.x — асинхронный фреймворк для быстрого отклика бота. 
• SQLite (aiosqlite) — локальная БД для связи Telegram ID ↔ Marzban UUID ↔ статусов платежей. 
• APScheduler — фоновый планировщик: каждые 10 минут проверяет истёкшие подписки, отключает их в Marzban и отправляет клиенту уведомление. 
3. Удалённые ноды (Sing-box / Xray)
Для распределения нагрузки и обеспечения высокой скорости используются удалённые серверы в разных странах, подключённые к единому центру.

<img width="433" height="614" alt="image" src="https://github.com/user-attachments/assets/fd9bca4f-e4d1-4790-91a9-8625df2cb99f" />

• Централизованное управление: На нодах установлены ядро Sing-box (или Xray) и агент Marzban-Node. Настройки передаются с главного сервера по защищенному каналу (mTLS-сертификаты). Не нужно заходить на каждый сервер вручную — всё обновляется автоматически из одной панели. 
• Маршрутизация трафика: Устройство пользователя подключается напрямую к выбранной ноде. Нода валидирует ключ, выпускает трафик в интернет нужной локации и отправляет статистику по трафику обратно на главный сервер.

🛡 Устойчивость к блокировкам и работа с AI
Обход режимных ограничений : Благодаря протоколу VLESS + gRPC / Reality, сервис сохраняет работоспособность даже во время глушения связи, ограничений мобильного интернета и работы провайдеров по «белым спискам» (включая периоды сигналов «беспилотная опасность»).
Полный доступ к AI-сервисам (Gemini, ChatGPT, Claude): Использование чистых IP-адресов на нодах позволяет беспрепятственно работать с нейросетями и зарубежными сервисами без регулярных банов, "капч" и ошибок доступа, с которыми сталкиваются пользователи обычных VPN.
